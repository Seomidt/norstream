# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

Everything drawn on screen also runs on Android TV. Read `docs/ANDROID-TV.md` (canvas, focus, checklist) before changing layout or adding a Pressable.

Colours come from `useTheme()`/`useStyles(makeStyles)` (light and dark, following the sun); never read `theme.colors` in a screen. See `docs/ANDROID-TV.md` section 4b.

Builds are made from chat via the GitHub workflow, never EAS: read `docs/BYG-FRA-CHAT.md` before triggering one.
